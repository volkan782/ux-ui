# Barber Booking

A mobile-first booking concept for customers who want to choose a barber service, see price and availability, and confirm an appointment without waiting for messages.

Current status: problem framing, one consented retrospective interview, persona/journey and competitor usability/accessibility audit, and a justified problem/solution focus documented. Wireframes, prototype and usability validation are not yet complete. No final-project acceptance is claimed.
